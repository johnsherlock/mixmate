## Conversion and CSP decisions

Pinned `soundcraft-ui-connection` 7.1.0's common Channel constructor maps `faderLevel$` through exported `faderValueToDB`; AUX masters use `.mix`, while inherited SendChannel/AuxChannel selects `.value` with the same conversion. Readouts may therefore use that pure conversion, including minus infinity for received zero; missing values remain unavailable and the mock's -60 dB floor is never used. Caps display normalized protocol position. Pan remains explicitly normalized 0..1, because a human L/R interpretation has not been qualified here.

Static CSP cannot express arbitrary RFC1918 IPv4 CIDR ranges. Live allows the required `ws:` scheme only; the sole transport constructor validates every target as canonical private IPv4 before opening it and keeps its socket private. It permits no HTTP fetch, generic request or public WebSocket target. Demo keeps `connect-src 'none'`. Production import-graph tests assert this boundary, and all entries retain asset/inventory proof before offline readiness.

## Session, readiness and lifecycle contract

The transport holds its socket in a closure and exposes only explicit connect/disconnect plus copied current-state snapshots/subscription. It has exactly three literal send sites: INIT on an open current socket, ALIVE once per second while open, and heartbeat response only to `2::`. There is no public socket or generic sender, inherited input writer, queued command or retry path. Constructor/send/close failures are terminal and clear observations. Generation and readyState checks reject stale/closed callbacks; a subscriber disconnecting during the open notification cannot trigger a later INIT or keepalive.

The observation provider owns a Map for one current socket and exposes copies. Ui24 model receipt is required before projecting profile-backed output/source availability. A known unsupported model closes/clears rather than claiming Ui24 capabilities. Socket-open, model-unverified, partial state and received AUX state are distinct. Initial qualification requires received Ui24 model plus at least one received output level whose `.matrix` explicitly says AUX; the 15-second connect/state deadline stays active otherwise. This is not a claim that all fields initialized. A 30-second silence timeout independently closes/clears; heartbeat/data traffic establishes socket responsiveness, not synthesized mixer values. No timeout reconnects automatically.

Each observed output remains separate; reciprocal, non-conflicting link metadata and both known AUX modes may share an app-owned display colour from the accepted palette. That never merges levels/names, assumes five pairs or fabricates stereo state. A known AUX can open its actual observed i/l/p/f sends; partial sends retain missing level/pan/link fields as unavailable, and name-only source metadata does not create a send. FX intrinsic stereo remains explicitly library-profile evidence. Matrix/unknown-mode slots do not open ordinary AUX views. Group editing/navigation persistence is deferred to F04, and EQ/snapshot/record/native actions remain disabled. Meter placeholders are unavailable until S04.

The compact connection affordance opens a dialog; it reads existing local profiles/preferences and never saves live state or changes rig definitions. Manual Connect works while settings load or fail. User interaction marks the target as owned; a late read cannot substitute a saved address, infer a rig by IP, connect, or repopulate state. Changing a profile/address clears synchronously. A browser constructor failure is not stored as address-invalid custom validity, allowing a deliberate retry at the same valid address. Hiding, pagehide and ordinary mode-link navigation disconnect and clear, while return/reopen remains inert. The existing input-fader connection test and isolated demo retain their independent behavior.
