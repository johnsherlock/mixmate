## Live throttled writes — F09-S05 (2026-11-18)

User decision: [ADR-0008 F09-S05](adr/0008-control-state-model.md#current-f09-s05-live-write-decision--2026-11-18) replaces the release-only clauses below. Summary of the private owner (`session-core.js`, `control-state-model.js`):

| Aspect | Rule |
| --- | --- |
| Start | Only an owned deliberate cap/key/preset gesture's preview schedules a step; begin keeps the full scope check. Receipts, selection, settings and track scroll never write. |
| Rate | Leading step immediately; then ≤1 step per `LIVE_STREAM_INTERVAL_MS` (level/group/pan 50 ms, GEQ 120 ms) with the latest preview; no queue. Release/keyup cancels the pending step and sends the final exact value only if different. |
| Step | Reducer `stream` event → new operation (`live: true`) → same per-ordinal dispatch guard (writer/receiver open and current, generation, topology/canonical settings, exact post-reducer authorization); synchronous reentrant relevant receipts stop the remainder. In-gesture checks are topology-only. |
| Budget | Next step waits `max(interval, paths × 1000 / budget)`: 100 SETD/s level/pan, 200 group, 250 GEQ; streamed steps defer while writer `bufferedAmount` > 4096 B; release always sends. Per-step reducer work is bounded by structural sharing. |
| Cancel | Cancel/Escape/pointercancel/focus loss after live steps leaves streamed values applied; status says so. |
| Sparse | Paths within 1e-9 of the last requested value are never sent, so the desk echoes every step. |
| Echo | Authorized values are journaled per path (≤128, 2.5 s). A receipt equal exactly or at the desk's 10-significant-digit format to a journaled, unsuperseded value is an own echo (actual updates, no cancel, consumes older entries); a rounded match of the current expectation counts toward observed-match ("desk-rounded"). Any other changed receipt is native → immediate stop, no rollback/replay. |
| Failure | Socket close/error/timeout clears state and stops; a throw records unknown delivery and touched-closure recovery; applied steps may remain. |
| UI | The active gesture's target stays editable while its echoes land; group members preview requested values; statuses say changes are sent live. |

The current policy is [ADR-0008's F09-S04 decision](adr/0008-control-state-model.md#current-f09-s04-peer-editor-decision--2026-11-17). PR #42's final affirmative review, passing checks and [exact-build firmware matrix](f09-s04-firmware-validation.md) own delivery/acceptance. The former S03 policy below is historical.

An explicit connection owns a private typed writer plus receive-only companion, same validated address/generation. The companion sends only INIT/ALIVE/heartbeat and exclusively populates bounded actual/provider/meter state; writer snapshots never interleave. Both must be open; target-specific model/modes/topology and actual values must be known/compatible. Either failure/close/timeout or lifecycle invalidation closes both and clears state, with no auto-reconnect. The literal read-only factory stays one connection, and level-only cannot gain pan through options. No socket/sender/raw plan escapes.

Qualified faders self-select their typed target on cap/key begin; no name selection or Enable/Disable step is required. Pan opens immediately editable when qualified. Private authority is per opaque owned gesture, deliberate release/key release/preset only. Native/current-scope changes cancel obsolete gesture/intent, update raw actual and allow a new deliberate gesture automatically on current compatible state. Unrelated value receipts preserve disjoint intent. Unequal linked actuals remain read-only until compatible. A raw precision difference is not an ACK or a permanent product failure; current complete compatible state is ready without manual rearm.

All-returned observations remain bounded to 2.5 seconds, exact fresh per-path matches mean observed-match without correlation/causality, and no matches mean sent-unverified. Absolute gestures can explicitly supersede the observation wait immediately; old receipts cannot confirm newer intent. Requested caps and diagnostics are distinct from received numeric values. Identical retained requested vectors are no-ops, never replay. Groups use a fresh finite actual anchor and one common cached clamped delta at **each** gesture, zero local reference and last-gesture requested delta; no cumulative stale coordinate overrides native changes.

A group overlapping outstanding local writes waits for every original touched component path's actual receipt after its own preauthorization cutpoint before reanchoring, regardless of exact-request match. These bounded basis dependencies persist across subset/context selection, refresh on historical-scope receipts and retire once complete. Incomplete/reentrant/unknown dispatch requires the stronger full touched closure's strictly post-invalidation-floor compatible receipts, covering unattempted paths. No manual Enable is needed once genuine state recovers. Scope shrinking cannot bypass uncertainty; fully recovered components do not contaminate later disjoint work.

Each ordinal revalidates private writer/receiver openness/generation, typed topology/canonical settings and exact post-reducer outstanding authorization. Any synchronous reentrant relevant value receipt stops the remainder, even exact; browser asynchronous receipts after the stack supply actual normally. Exact outstanding send return/throw settles its own ID once after replacement. Counts/unknown throw remain diagnostic; dispatch is non-atomic and hardware application/balance cannot be guaranteed. No queue/retry/replay/rollback/getter/postwrite INIT. F08-S01 remains the physical release gate.

# Owned level, group and pan runtime — F09-S03

## Current runtime policy — 2026-11-17

The containing F09-S03 PR integrates [ADR-0008](adr/0008-control-state-model.md) privately in `session-core.js` for existing level/group/eligible-pan controls only; review/merge status is tracked by [F09-S03](stories/F09-S03.md). This section supersedes historical timeout-as-failure, fresh-lease-per-move and global unrelated-value-invalidation wording in the linked historical contracts. Exact serializers/types/ranges, literal factory capabilities, equal actual linked prerequisites, opaque gestures and deliberate commit remain unchanged. Pure scopes/public Maps/diagnostic vectors grant no send authority. Historical `createAuxLevelGuard`/`createAuxPanGuard` remain no-transport compatibility/test helpers; production instead uses the reducer plus the private current-owner typed dispatch guard, never a caller plan.

All-returned dispatch waits at most 2.5 seconds for exact raw fresh matches on **every** path after its own immediate preauthorization cutpoint. Complete matches are observations, never a correlated ACK. Without every match, unchanged same-scope expiry is terminal **sent-unverified**, retaining permission and a distinct requested coordinate for a **new explicit gesture**; equal requested intent is a no-op, not retransmission. Received numeric/per-side values are never replaced with intent. Pending blocks gestures; timer and every receive/control/snapshot entry check dual clocks, dispatch expiry and elapsed time. Backward/skewed clocks revoke authority. A delayed receipt cannot revive an expired operation.

Native changes to the currently qualified value closure (including away/back), relevant received mute/post/postproc processing, topology/mode, canonical profile/group definitions and lifecycle cancellation revoke permission. Unrelated value receipts do not revoke disjoint scope authority. Each ordinal revalidates the private current socket/generation, visibility, exact typed topology and canonical settings before synchronous authorization/send, and verifies the resulting exact owned dispatching flight/ordinal/count after the reducer authorization transition (which can revoke without throwing); any reentrant receipt during dispatch stops the remainder. Exact outstanding send return/throw settles its operation ID even after selection/generation replacement; counts cannot migrate to newer operations. No queue/retry/replay/rollback/reconnect/probe is added. Send return is not application; partial operations and unknown throws may have changed some hardware values.

After any authorized write, invalidation retains a recovery floor for the **entire touched closure**, including unattempted paths. Select-away/back, group-membership shrink, topology split and other overlapping selections cannot bypass it: any overlap requires all original uncertain closure paths to recover. One per-path barrier record retains bounded closure membership; unresolved intersecting components are conservatively joined, while fully recovered components are pruned before later invalidations so genuinely disjoint targets stay independent. The recovery journal/closure is explicitly capped at1024 typed paths, above the finite supported path universe. Complete compatible receipts strictly after the floor plus explicit rearm are required; one fresh side or the invalidating receipt cannot recover. An explicit new socket generation needs its own complete actual state and never confirms an old operation. Requested caps persist while owned; cancellation removes cap authority and retains separately labelled diagnostic intent/counts. No physical/firmware/precision or hardware-balance qualification follows from fake tests. F09-S04 and F08-S01 remain open; no GEQ/new command class is enabled.

## F06-S05 AUX EQ filters (user request 2026-11-21)

The typed `geq` scope may include the output's `eq.hpf` / `eq.lpf` members (hpf of every side, then lpf of every side) when all are received and a pair is equal. `setEqFilter({ filter, enabled, value })` is a deliberate non-streamed one-shot (`begin` → filter preview → `commit`); `previewEqFilterGesture(token, intent)` streams a handle drag through the unchanged throttle (leading step, then ≤ 1 per max(120 ms, paths × 1000 / 250)), backpressure deferral, sparse rule and release-only-if-different commit. The owner clamps the intent (strictly inside (0, 1) while enabled, hpf ≥ 0.1 below lpf, exact 0/1 off) and refuses with no write when there is no room or the scope lacks filters. Own echoes and native changes follow the GEQ rules (a native filter change stops the gesture; no rollback). Busy/updates: filter gestures set the same `gestureActive` / `pending` / `dispatching` flags. Contract: [EQ contract](iem-aux-eq-contract.md#f06-s05-aux-eq-filters--2026-11-21).
