## Implemented runtime contract

Only `createAuxControlSession` exposes pan selection/enable/gesture methods. The literal legacy factories retain their original connection-only or level/group-only capabilities even with malicious upgrade options. The socket and authoritative observations, receipts and revisions remain private. Pan commits serialize only the S01 normalized i/l/p AUX-send pan forms; there is no public sender, arbitrary path/array authority or input/master fallback. Equal pan prerequisites use exact raw values, independently of output master/send levels.

A selected pan context excludes level/group control. Explicit arming is never stored. Begin captures a fresh opaque lease; preview validates and caches the three-decimal actual wire value without changing received observations. Commit accepts that exact gesture only, revalidates each ordinal against current owned state and captures that path's receipt immediately before authorization. No per-move or generic input/change event sends. Fresh matching observations on both paths are required within 2.5 seconds, including elapsed checks when timers stall or clocks move backward. These are observations, not a correlated ACK. Pending blocks another operation; wrong fresh values, external changes, topology/context changes, timeout or partial delivery cancel/disarm. Send-return accounting remains diagnostic; product feedback describes possible partial changes and explicit recovery. No rollback, automatic retry/replay or reconnect.

Bank and modal gesture roots are separate. Dialog leases coordinate connection/groups/pan; per-opening callbacks capture the lease, and handled shared Close/Escape events cannot close a replacement owner opened reentrantly by focus restoration. Closing immediately disables range/presets/Enable before session emits or focus callbacks; native pan changes cancel preview, while received values remain authoritative. Legacy `disarmLevel`/`invalidateLevelContext` are intentionally broad safety cancellation aliases; level-specific begin/preview/commit/cancel cannot operate pan tokens. Only current private capability snapshots enable controls, never copied presentation Maps.
