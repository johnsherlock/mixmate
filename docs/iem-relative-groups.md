# Relative AUX group levels — F05-S03

## Current F09-S08 travel to −∞ in display-scale units — 2026-11-20

**User decision (2026-11-20, F09-S08), supersedes the −70 dB group floor:** "moving the group faders should stop when one hits −∞, not −70 dB." A group applies **one common delta in display-scale units** ([fader-scale.js](../src/iem/fader-scale.js) `positionToScale`/`scaleToPosition`), not raw dB. Above −70 dB a scale unit is a dB (equal dB = equal distance, as before); in the short bottom segment (scale −70…−75 ↔ desk position ≈0.0252…0) members keep moving equal on-screen distance. Limits: up stops when the loudest member reaches the top (scale +10, desk position 1); down stops when the quietest member reaches the bottom (scale −75, desk position 0, −∞). Groups may now write position 0; the endpoint member lands exactly on 1 or 0 (inward 1e-12 guard as before). Anchors are fresh finite received positions; silent members are valid anchors at scale −75, so a group containing one can move up (it rises from the bottom) but allows no further downward travel. The anchor member field is `scale` (was `db`); `GROUP_FLOOR_DB` is replaced by `GROUP_FLOOR_SCALE = −75` / `GROUP_TOP_SCALE = +10`; `groupTravel` returns `referenceScale`. The Δ readout shows the common delta in these dB-equivalent scale units (one decimal). Wire values, guards, allowlist and the peer-editor model are unchanged. The fader law moved to [fader-law.js](../src/iem/fader-law.js) (re-exported) to avoid a module cycle.

**Group strip display (F09-S08).** The cap is the maximum over members of each member's displayed position: received, or this owner's requested value while its own member gesture/live steps are active; position 0 counts. "Level unavailable" shows only when controls are absent or no member has any finite position, never transiently during member gestures or own-echo windows. Presentation grants no authority: a group gesture the session cannot anchor yet (for example, own echoes outstanding) simply gets no token.

The −60 dB figures in the 2026-11-19 paragraph are superseded.

**User decision (2026-11-19):** live level faders use a Demo-style dB-linear display scale ([fader-scale.js](../src/iem/fader-scale.js)): +10…−60 dB linear in dB, then a short bottom segment that maps desk position linearly from the −60 dB position to 0 (−∞). The group cap starts at the loudest member's received level on that scale; a scale move of N dB is one common delta of N dB, so every member above −60 dB moves the same distance (the previous raw-position display made equal dB look like a "ratio"). `GROUP_FLOOR_DB` is now **−60 dB**: the bottom of travel puts the quietest member exactly at −60 dB (the bottom of the dB-linear span); the top still puts the loudest at desk position 1 (+10 dB); a member already below −60 dB gives zero downward travel; a group never writes position 0. The session API, anchor, clamp and wire values are unchanged: the view converts scale ↔ desk position at its boundary. Since F09-S06 a group's received-basis/own-echo wait is bounded by the 2.5 s window ([ADR-0008 amendment](adr/0008-control-state-model.md#f09-s06-amendment--2026-11-19)). The F09-S05 floor text below is superseded.

## F09-S05 full-range travel and live preview — 2026-11-18

The fixed ±12 dB relative window is removed. The group fader is the **loudest member's fader position**: its cap starts at the loudest member's received position and moves along the normal fader law. For the frozen fresh anchor (member dB values `d[i]`, reference `r = max d[i]`), a requested position `p` gives `delta = dB(p) − r`, clamped to the whole-group travel:

- **upper** `= min(GROUP_MAX_DB − d[i])`: the top of travel puts the loudest member exactly at fader position 1 (within the existing 1e-12 dB inward endpoint guard), everyone else raised by the same dB;
- **lower** `= min(0, max(GROUP_FLOOR_DB − d[i]))` with `GROUP_FLOOR_DB = −100 dB` (position ≈ 0.00125, visually the bottom of the fader): the bottom of travel puts the quietest member exactly at the floor, everyone else lowered by the same dB. If the quietest is already below the floor there is no downward travel and nothing is forced up.

**Min definition (superseded by F09-S08).** Historically a group never wrote position 0 because one common dB delta cannot reach −∞ evenly. Since F09-S08 the delta is in display-scale units, so the bottom of travel writes position 0 for the quietest member, and silent members re-anchor at scale −75. Display and live mapping: [relative-groups.js](../src/iem/relative-groups.js) `groupTravel`/`groupReferenceDelta`/`groupReferencePosition`; the private session converts the position to the delta against its own anchor, never a presentation value.

One common delta, deduplicated paths and the exact cached preview are unchanged; the cap stops at the clamp, and further travel sends nothing. The Δ readout shows the requested gesture delta. While a group gesture (or its last step's observation wait) is active, member strips move with the requested common-delta values (dashed cap, "Group requested …"), distinct from their received level text, which follows the companion echoes. Linked stereo member pairs preview together.

Streaming specifics: the gesture keeps its own base delta, so steps never compound with echoes; a group never re-anchors while any member path has an outstanding own echo (≤2.5 s), and the post-cutpoint basis rule still applies. A native member edit stops the stream immediately.

## Implemented math and authority

`relative-groups.js` expands each saved source through the strict equal-linked S01 closure, then deduplicates the Cartesian paths in first-member order. Distinct sources can have different levels; linked closure inconsistencies never get averaged. A frozen baseline retains exact received normalized values and continuous dB. A 72-step upper-bracket bisection inverse preserves finite positive outputs without the library's 0.1 dB display/1e-11 normalized-output rounding. One delta is constrained by the tightest member headroom; any floating-point endpoint correction moves that same delta inward for all members, and a shared |Δ| below 1e-12 dB is a no-op. Neither baseline nor independent outputs are clamped/rounded. Zero delta preserves raw values and sends no commands.

The core accepts any finite requested delta and limits it to common physical/profile headroom; the UI offers ±12 dB with 0.1 dB request steps. Group range `step=any` preserves the exact non-step shared boundary. Preview caches the exact actual common delta in the private gesture and commit consumes that cache, not a browser-sanitized input value. Preview never replaces the baseline. Each new explicit gesture starts at local Δ zero against fresh authoritative values; zero is a command reference, not a received group level or cumulative group state.

The private control session reads the validated canonical settings repository and binds the controller's actual local profile ID independently of its persisted selectedProfileId and IP. Group selection exposes only group ID/AUX index; no raw member/value array or caller observation Map enters dispatch. Current group identity/membership/order is checked against the captured signature before preview/commit/each ordinal and readback; changed/missing definitions clear authority. Group/native/topology/profile/target/dialog/navigation/hide/clock/connection changes invalidate/disarm rather than update a live baseline. Opaque plan/gesture identities, strict current socket journal, ordinal receipt cutpoints, reentrant checks and 2.5-second confirmation are the S02 path. Expected values come from each typed command, never the common delta argument. Partial delivery stops without rollback/retry/replay; diagnostic counts remain in snapshots and user copy says some levels may have changed.

Group name/shortcuts keep expand/collapse. The separate Select level button and explicit Enable choose relative control without navigating. GROUP MASTER identity, RELATIVE Δ/reference text and selected highlight distinguish its local coordinate. No group VU or aggregate level is fabricated. Expanded groups still omit the AUX master and retain ordered/unresolved members. Footer placement matches source metadata slots, preserving source/group travel. A control-state change discovered during a meter publication updates disabled UI immediately; unchanged meter publications remain meter-only with stable bank/cap/scroll nodes.
