## Implemented math and authority

`relative-groups.js` expands each saved source through the strict equal-linked S01 closure, then deduplicates the Cartesian paths in first-member order. Distinct sources can have different levels; linked closure inconsistencies never get averaged. A frozen baseline retains exact received normalized values and continuous dB. A 72-step upper-bracket bisection inverse preserves finite positive outputs without the library's 0.1 dB display/1e-11 normalized-output rounding. One delta is constrained by the tightest member headroom; any floating-point endpoint correction moves that same delta inward for all members, and a shared |Δ| below 1e-12 dB is a no-op. Neither baseline nor independent outputs are clamped/rounded. Zero delta preserves raw values and sends no commands.

The core accepts any finite requested delta and limits it to common physical/profile headroom; the UI offers ±12 dB with 0.1 dB request steps. Group range `step=any` preserves the exact non-step shared boundary. Preview caches the exact actual common delta in the private gesture and commit consumes that cache, not a browser-sanitized input value. Preview never replaces the baseline. Each new explicit gesture starts at local Δ zero against fresh authoritative values; zero is a command reference, not a received group level or cumulative group state.

The private control session reads the validated canonical settings repository and binds the controller's actual local profile ID independently of its persisted selectedProfileId and IP. Group selection exposes only group ID/AUX index; no raw member/value array or caller observation Map enters dispatch. Current group identity/membership/order is checked against the captured signature before preview/commit/each ordinal and readback; changed/missing definitions clear authority. Group/native/topology/profile/target/dialog/navigation/hide/clock/connection changes invalidate/disarm rather than update a live baseline. Opaque plan/gesture identities, strict current socket journal, ordinal receipt cutpoints, reentrant checks and 2.5-second confirmation are the S02 path. Expected values come from each typed command, never the common delta argument. Partial delivery stops without rollback/retry/replay; diagnostic counts remain in snapshots and user copy says some levels may have changed.

Group name/shortcuts keep expand/collapse. The separate Select level button and explicit Enable choose relative control without navigating. GROUP MASTER identity, RELATIVE Δ/reference text and selected highlight distinguish its local coordinate. No group VU or aggregate level is fabricated. Expanded groups still omit the AUX master and retain ordered/unresolved members. Footer placement matches source metadata slots, preserving source/group travel. A control-state change discovered during a meter publication updates disabled UI immediately; unchanged meter publications remain meter-only with stable bank/cap/scroll nodes.
