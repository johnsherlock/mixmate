## Exact forms and implemented pure boundary

The only pan form admitted by these primitives is `3:::SETD^<source>.aux.<0..9>.pan^<position>`, source `i.0..23`, `l.0..1` or `p.0..1`. Input descriptors contain exactly sourceId/auxIndex (plus value for a command); unknown fields, accessor/prototype/coercion shapes, symbols and noncanonical/out-of-profile IDs are rejected. No raw path/string sender. Requests must be JavaScript finite numbers 0..1 before normalization; invalid input is never clamped into permission. The pinned normalization is `round((value + Number.EPSILON) * 1000) / 1000`, with negative zero rendered as zero. Expected values use that actual wire-rounded number; received baselines retain their exact unrounded values.

`resolveAuxPanTargets` uses observations from one current owned journal. It requires explicit mono source metadata, valid reciprocal non-overlapping output links, both AUX modes and both received numeric pan positions. Source partner pan is never read/written as a fallback. A level/mute/name alone cannot manufacture a missing pan, and unequal pans do not become eligible by first rounding them to the same display value. Raw normalized pan observations for unsupported stereo/FX/mono-destination cases continue through the existing read parser unchanged.

`createAuxPanGuard` reads a closed-over owner callback with actual current observations, path receipts, open/visible booleans and integer generation/context/panRevision. Methods do not accept replacement Maps/context. The later private S02 factory must own that callback/journal and advance panRevision on actual changes, including away/back; repeated identical receipts advance only path receipt evidence. Selection/profile/AUX/group/dialog/lifecycle/topology changes invalidate context and disarm. Level/pan arming contexts must be mutually exclusive, with no restored settings permission.

Explicit arm resolves/captures the exact baseline. Prepare validates strict input, records actual normalized command values and creates an immutable opaque plan; newer intent supersedes older plans. Each ordinal is authorized once in order with fresh owned-context validation and its immediate pre-authorization receipt cutpoint. No queue, foreign/cloned plan, skipped/repeated ordinal, or partial resume is allowed. These methods only return typed messages for fake tests/future private synchronous dispatch; no socket, sender, timer or state subscription is present.

Readback validates current topology without requiring intermediate equality, then checks each exact path for a fresh receipt and exact actual wire value. Partial expected echoes stay unconfirmed; fresh different values conflict, malformed/regressing receipt journals invalidate, and premature/incomplete dispatch cannot confirm. Old same-value state and unrelated receipts do not count. Matching observations are not correlated protocol acknowledgements or proof of cause. S02 must add its own private immediate send/exception checks, actual send-return diagnostics, bounded confirmation timer plus elapsed checks and visible pending/conflict/unconfirmed state. Any interruption stops/disarms without rollback/retry/replay.
