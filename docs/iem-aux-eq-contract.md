## Resume contract proposal — not implemented or allowlisted

- Pure typed output-band form: `3:::SETD^a.<0..9>.eq.peak.<0..30>^<value>`, strict finite numeric0–1, no arbitrary paths/fields, raw arrays or input/main fallback. Use full finite command precision unless later evidence requires a wire quantization policy. Typed plans must expect the exact serialized value. Read-only `a.N.eq.bypass` is a received0/1 boolean prerequisite/status; it grants no bypass-write capability.
- Require owned current Ui24 model, explicit AUX mode, mono or reciprocal non-conflicting output link metadata and every band's actual received value on each side, with receipt evidence. A linked pair has31 paths per side; preserve both raw profiles and block control when unequal instead of silently equalizing. No main `.eq.peak.l/r`, source EQ, gain, AFS, routing, preset metadata, HPF/LPF, filter slope, bypass or shelf write forms.
- Freeze a complete current profile/context for one explicit gesture. Generation, target/selection/profile, AUX/matrix/link, EQ/native-processing changes invalidate; an external away-and-back edit must not hide behind equal final values. Future owner-closed context revisions and per-path receipt counters are required. Opaque latest-intent ordered plans revalidate before every authorization. Partial fresh echoes after complete dispatch remain pending until every required path matches; conflicting/new native state stops/disarms. Exact send-return/deadline/reentrant-stop behavior must reuse the established runtime safety policy in S04. No retry/rollback/replay or incoming-triggered sends.
- Pure requested curve is separate from received bands: finite bounded ordered log-frequency samples, evaluated at the31 native display centres; reject a requested band outside±15dB rather than silently clipping independent bands. Point/draw modes remain distinct UI intents in S04, with no reverse fitting of native bands into three points. Actual per-side band readback remains authoritative after native changes; a connected line through band values is not a proven DSP response.
- Reset proposal: only the selected verified31-band GEQ profile(s) to.5, with the same full baseline/arming/readback guards. Preserve bypass/filter/AFS/dynamics/preset fields; do not call native `resetGraphEQ`. No blanket native reset is authorized by this proposal.
- Dedicated shelves remain **unverified/parked**. Manual/native HPF/LPF are separate filters, not shelves and not a silent replacement for mock cuts. The accepted mapping may proceed with verified GEQ-only scope later, with explicit limitations; no dedicated shelf/cut control or phantom parametric DSP is enabled here. Physical DSP centres/response, firmware precision, field coverage, native edits and link mirroring/fresh echoes remain F08 qualification.
