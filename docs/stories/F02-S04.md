- Durable saved feedback occurs only on committed transaction; temporary, failed and conflict states remain distinct with useful recoverable feedback. Never persist live values, arming, baselines or pending controls.
- Reproduce manual/saved/duplicate-IP, unavailable storage, abort, conflict and late completion cases with fake/actual local storage as appropriate. Record exact build/device/browser/error for the unknown tablet issue when separately available; do not claim it fixed from a hypothesis.
- Preserve disconnect/disarm on rig/context changes and safe local backup/recovery. Browser tests do not certify tablet persistence or physical qualification.
