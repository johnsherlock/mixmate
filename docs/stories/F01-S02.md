# F01-S02: Offline asset and lifecycle verification

Feature: [F01](../features/F01.md)
Status: Done — merged in PR #8
Depends on: F01-S01

## Outcome and scope

Fix evidenced distribution defects and add meaningful production-build/service-worker tests using local fixtures and fake transports. Preserve the existing connection test and preview.

## Acceptance criteria

Every emitted asset is verified before offline readiness; incomplete cache and failed update do not claim readiness or replace a valid installed version; waiting updates cannot interrupt an open session; relative URLs and scope work under /mixmate/; cold offline launch and disconnect/no-reconnect behavior are covered where automatable.

## Validation and delivery

- Follow repository AGENTS.md and ADR-0001. Keep changes scoped to this story.
- Use fake mixer transports for automated tests; never automate real parameter writes.
- Run `npm test` and `npm run build` before opening a PR. Add meaningful checks for the behavior changed.
- Record automated results separately from device observations. Never mark a hardware gate passed without evidence.
- One story branch and PR; request `@codex review`, fix findings and request review of the final revision.
- Merge only with passing required checks and affirmative Codex review applicable to the final changes. Silence or a local agent self-review is not approval.
- Update story/feature/backlog status and evidence links in the story PR; do not begin the next story until this PR is merged.

## Evidence and completion

- Reproduced missing-entry verification failure with a failing service-worker test before implementing repair.
- `npm test`: 26 passed. `npm run build`: passed; eight emitted/precache assets, worker version `79f112fe123a3681`.
- Build-time SHA-256 expectations verify every cached/downloaded response. Repair rejects newer deployment bytes, redirects and failed/opaque responses; worker template changes also change cache version.
- Registration, activation and verification share a 15-second deadline; closed message ports and attempt ownership prevent late results replacing current UI status. Diagnostics include the verified worker version.
- Production inventory/subpath tests and worker VM tests cover cold offline fetch, repair, corruption, failed/waiting updates and scope isolation. Actual app-entry tests use fake DOM and fake sockets for disarm/clear/hide/pagehide/reopen/no automatic connection.
- No mixer connections or parameter writes; mockup HTML/CSS/gestures unchanged. Device installation, browser engine behavior and transport remain unverified for S03.
- [PR #8](https://github.com/johnsherlock/mixmate/pull/8) merged as `3f93d3308e2da63a9bd3f307a99d8cf109ec74aa` after passing CI and affirmative Codex review of final head `e137acb84c3411ed7e67385c7b6e4c09a0929807`.
