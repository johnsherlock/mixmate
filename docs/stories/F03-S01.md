## Outcome and scope

Verify AUX master/send/pan, source inventory, output mode and source/output stereo metadata against library/native-client evidence and sanitized device captures.

## Acceptance criteria

Each accepted path/type/range has provenance; missing fields stay unknown; matrix slots are distinguished; source coverage includes verified input, line, player and FX categories; parsing is bounded and rejects malformed data.

## Validation and delivery

- Follow repository AGENTS.md and ADR-0001. Keep changes scoped to this story.
- Use fake mixer transports for automated tests; never automate real parameter writes.
- Run `npm test` and `npm run build` before opening a PR. Add meaningful checks for the behavior changed.
- Record automated results separately from device observations. Never mark a hardware gate passed without evidence.
- One story branch and PR; request `@codex review`, fix findings and request review of the final revision.
- Merge only with passing required checks and affirmative Codex review applicable to the final changes. Silence or a local agent self-review is not approval.
- Update story/feature/backlog status and evidence links in the story PR; do not begin the next story until this PR is merged.
