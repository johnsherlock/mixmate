# F06-S04: Approved EQ controls

Feature: [F06](../features/F06.md)
Status: Planned
Depends on: F06-S03

## Outcome and scope

Implement the ADR-0002-authorized requested-curve mapping using F06-S03's verified pure AUX GEQ-band primitives and a separately reviewed runtime ownership/write/readback integration. F06-S03 supplies no shelf/filter runtime guards. Native displayed centres are an approximation basis, not verified DSP centres. Do not actuate the real desk during development.

## Acceptance criteria

Point/draw modes remain mutually exclusive; portrait sliders sit below graph; actual per-side GEQ-band readback is authoritative, approximation limits are visible and no parametric hardware is invented. Preserve unrelated EQ state and both received stereo sides; resets are scoped; stale baselines cannot overwrite native edits; tests use fake transports. Dedicated shelves/cuts/filters remain unverified and parked; no corresponding runtime writes or silent substitution. Display-centre sampling and a line through band values must not claim measured DSP response.

## Validation and delivery

- Follow repository AGENTS.md, ADR-0001 and [ADR-0002](../adr/0002-deferred-qualification-and-authorized-controls.md). Feature-class authorization is accepted; protocol evidence and narrow guards remain mandatory. Keep changes scoped to this story.
- Use fake mixer transports for automated tests; never automate real parameter writes.
- Run `npm test` and `npm run build` before opening a PR. Add meaningful checks for the behavior changed.
- Record automated results separately from device observations. Never mark a hardware gate passed without evidence.
- One story branch and PR; request `@codex review`, fix findings and request review of the final revision.
- Merge only with passing required checks and affirmative Codex review applicable to the final changes. Silence or a local agent self-review is not approval.
- Update story/feature/backlog status and evidence links in the story PR; do not begin the next story until this PR is merged.
