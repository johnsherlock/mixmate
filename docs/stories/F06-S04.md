## Acceptance criteria

Point/draw modes remain mutually exclusive; portrait sliders sit below graph; actual per-side GEQ-band readback is authoritative, approximation limits are visible and no parametric hardware is invented. Preserve unrelated EQ state and both received stereo sides; resets are scoped; stale baselines cannot overwrite native edits; tests use fake transports. Dedicated shelves/cuts/filters remain unverified and parked; no corresponding runtime writes or silent substitution. Display-centre sampling and a line through band values must not claim measured DSP response.
