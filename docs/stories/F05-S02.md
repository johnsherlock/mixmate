## Outcome and scope

Implement the ADR-0002-authorized per-source send and AUX master level controls using F05-S01 verified guards and confirmation readback. No real-desk actuation during development.

## Acceptance criteria

Writes require explicit current selection arming and received level/link/mode metadata; both stereo dimensions are preserved; disconnect/hide/selection changes cancel/disarm; silence and dB mappings are verified; gestures match the prototype; tests use fake sockets only.
