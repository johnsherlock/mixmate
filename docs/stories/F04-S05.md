## Outcome and scope

Fix three user-reported phone problems from a live **All Mixes** session with no AUX selected: the group editor listed no channels, a group could not be deleted, and Edit Groups forced a saved-rig setup detour. Local definitions only; no mixer writer, allowlist, transport or dependency change.

## Acceptance criteria

- With no AUX selected, the editor offers the union of sources whose sends were received on any currently browsable AUX output. Selecting an AUX keeps the existing per-AUX catalog. Retained/unresolved member IDs stay visible, selected and preserved in saved order.
- A saved group has an explicit **Delete group** action with an in-dialog confirmation (Keep group / Delete group) inside the editor's existing dialog lease. Deletion commits through the guarded settings updater with the existing saved/temporary/conflict feedback; stale groups are rejected, never silently replaced.
- Edit Groups opens directly. With no saved rig bound, groups belong to one device-local definition set whose stable ID is created lazily by its first saved group. A bound saved rig keeps its own groups exactly as before; nothing is moved between owners implicitly. Manual address connections never bind a saved rig.
- Settings schema version 2 adds `localDefinitions`. Version-1 documents and backups migrate purely on read (reading never writes); unknown/newer versions remain untouched. Exports are version 2.
- Definition-owner changes cancel obsolete control intent and revoke group selection.
