# F08-S05 — Live channel meters and peak indicators

Feature: [F08](../features/F08.md)

Status: Planned.

## Outcome

A performer can see live channel signal and spot peaks while viewing individual faders in All Channels or an expanded group.

## Acceptance criteria

- Each individual channel fader displays its received source meter and a visible peak indicator inspired by the native desk UI. Preserve the tap and stereo handling in the [meter contract](../iem-meter-contract.md).
- Verify the native peak behavior and available data before choosing the threshold and hold. If using a sample-based hold, identify it as such and distinguish it from hardware clipping. Label the meter as a source signal so it cannot be mistaken for the channel's contribution to the selected AUX.
- Clear the peak indicator when samples go stale or the session clears. Unavailable readings stay distinguishable from a fresh reading at the meter floor.
- Meter updates preserve fader touch and scroll behavior and send zero writes.

## Validation

Exercise missing, fresh, peaked and stale samples with fake transport. Compare the visible behavior with the native UI on a desk and record the build, device, firmware and observed results.
