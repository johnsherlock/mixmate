# F02-S02: Rig profiles and preferences

Feature: [F02](../features/F02.md)
Status: Planned
Depends on: F02-S01

## Outcome and scope

Add named rig profiles, addresses and display/navigation preferences.

## Acceptance criteria

Profiles use local IDs rather than IP as identity; switching profiles disconnects/disarms; no automatic connect; storage is namespaced to MixMate and profiles; default addresses are editable.
