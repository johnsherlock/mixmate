Connection notes & diagnostics +
The mixer uses an unencrypted local WebSocket. Some browsers block this from an HTTPS app, even after installation. A failed connection does not change the mixer. Try allowing local network access; no internet or account is needed at rehearsal.
Fader control sends input level changes only after you enable it and release the slider. Channel selection, connecting and enabling control do not move faders. Changing channel, disconnecting or hiding the app disables control. No mute, gain, routing, scene or network changes are sent.
